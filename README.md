A fully responsive, web-based version of the classic Ludo board game. Built with pure JavaScript, this game works smoothly on both Desktop 🖥️ and Mobile 📱 devices. Gather your friends and enjoy a digital match!

🔗 **[Play the Live Demo Here](https://shivam-042007.github.io/Ludo-Board-Game/)**

---

## 🚀 Features

* **Responsive Design:** optimized layout that fits perfectly on mobile screens and desktop monitors.
* **Classic Rules:** Implements standard Ludo gameplay mechanics.
* **Dice Animation:** Simple and interactive dice rolling experience.
* **Local Multiplayer:** Play with up to 4 players on the same device.

## 🕹️ How to Play

1.  **Start the Game:** Open the link on your browser.
2.  **Roll the Dice:** Click the dice to roll. You need a **6** to release a token from the base!
3.  **Move Tokens:** Navigate your tokens around the board based on the dice roll.
4.  **Win:** The first player to get all four tokens to the center "Home" triangle wins!

## 🛠️ Built With

* **HTML5** - For the board structure.
* **CSS3** - For the colorful design and responsive layout.
* **JavaScript** - For game logic, dice rolls, and token movement.
